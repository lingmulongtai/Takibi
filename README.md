# Takibi

夕暮れの海辺の焚き火を、リアルタイム WebGL2 レイマーチングと無限のプロシージャル環境音（Web Audio API）で再現したチルサイトです。外部ライブラリ・ビルド工程・録音ループ音源を一切使わず、100% プロシージャルな映像と音で永遠に燃え続けます。

**Live Demo:** https://lingmulongtai.github.io/Takibi/

## 特長

### グラフィック（マルチパス HDR WebGL2 パイプライン + 静的 G-Buffer キャッシュ）
- **静的 G-Buffer MRT キャッシュ (`RGBA16F × 2`)**: 砂浜の足跡・流木・ソフトシャドウ・環境光遮蔽を 2 枚の浮動小数点ターゲットへ事前ベイク（カメラ移動・時間帯切替時のみ自動再ベイク＋停止後フル品質リファイン）。通常フレームでは砂浜と薪のレイマーチ／シャドウ探索を 0 ステップにしつつ、炎の揺らぎ光・熾火の脈動・3D 波・流体炎を毎フレーム 60fps で合成します。
- **GPU Navier-Stokes 流体炎 (`192×168 RGBA16F`) & タイト AABB 3D ボリューメトリック積分**: 浮力・渦度閉じ込め・ウォームスタート Jacobi 圧力投影・2 次精度 MacCormack 移流で流体炎を毎フレーム計算し、タイトな境界ボックス（AABB）と空セル早期スキップで高精度かつ軽量に 3D 遮蔽描画します。
- **足跡と波打ち際を事前ベイクした `768×768 RGBA16F` 砂浜ハイトマップ**: 起動時に約 300 個の足跡・解析勾配・海岸勾配をすべて浮動小数点テクスチャへ焼き込み、ランタイムの高度取得を 1 テクスチャフェッチに高速化。
- **真の 3D レイマーチング波 & 空間ゲーティング**: 浅瀬で急峻化するトロコイド波を 3D 空間で直接レイマーチングし、砕波帯ローラーや Voronoi 網目泡は波が立つ領域だけで評価します。
- **深度遮蔽付き 3D 火の粉パーティクル**: インスタンシング描画による上昇・旋回する火の粉が、シーン深度バッファを参照して薪の前後を自然にすり抜けます。
- **映画品質 HDR ポストプロセス + CAS シャープニング**: Karis 加重ブライトパス、Jimenez ダウンサンプル／テントアップサンプル・ブルーム、暖色ハレーション、**AgX トーンマッピング**、5-tap Contrast Adaptive Sharpening（CAS）、60fps フレームペーシング＆バックグラウンドタブ自動一時停止。

### サウンド（無限プロシージャル Web Audio エンジン）
- **録音ループ不使用・完全に無限生成**: ブラウザ内でリアルタイム合成するため、継ぎ目や繰り返しがありません。
- **3 層の焚き火音響**:
  - 低い炎のうなり・燃焼音（視覚的な炎の揺らぎとリアルタイム連動）
  - 樹液や熾火のかすかな「チリチリ・ジュワ」音
  - ポアソン・クラスタスケジューラによる自然な「パチパチ」「バキッ」という薪のはぜる音（大きな破裂音に連動して 3D 火の粉も舞い上がります）
- **黄昏のさざ波**: 不規則な周期で寄せては返す波のうねり・砕け・引き波をステレオ定位で合成。

## 操作方法

| 操作 | 機能 |
| --- | --- |
| 画面下の「音をつける」または画面クリック | 焚き火・波の音をフェードイン再生 |
| 焚き火周辺をクリック / `Space` | 薪をくべる（炎・火の粉・パチパチ音が一時的に強まる） |
| マウス移動 | ごく穏やかな視差（パララックス） |
| `M` | サウンドのミュート / 解除 |
| `F` | 全画面表示の切り替え |
| `H` | UI の完全非表示（禅モード）切り替え |
| 設定ボタン | 焚き火 / パチパチ / 波の音バランス、空の時間帯（黄昏 / 藍時 / 夜更け）、画質（Ultra / High / Balanced、デフォルト `High`、リアルタイム FPS 表示） |

## ローカルでの起動

ビルド不要のネイティブ ES Modules 構成です。任意の静的 HTTP サーバーで配信してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くと表示されます。
