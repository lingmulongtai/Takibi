# Takibi

夕暮れの海辺の焚き火を、リアルタイム WebGL2 レイマーチングと無限のプロシージャル環境音（Web Audio API）で再現したチルサイトです。外部ライブラリ・ビルド工程・録音ループ音源を一切使わず、100% プロシージャルな映像と音で永遠に燃え続けます。

**Live Demo:** https://lingmulongtai.github.io/Takibi/

## 特長

### グラフィック（マルチパス HDR WebGL2 パイプライン）
- **3D ボリューメトリック・レイマーチング炎 (`RGBA16F`)**: 2層ドメインワープ 3D FBM と螺旋渦による上昇炎を、流木・炭化枝の正確な 3D 深度で遮蔽しながらボリューム積分。物理ベースの黒体放射（Blackbody）と炎カラーランプで、白熱する芯から黄金〜朱色の舌までを描写します。
- **足跡と砂丘を彫刻した `768×768 RGBA16F` 砂浜ハイトマップ**: 起動時に GPU 用浮動小数点テクスチャとして約 300 個の足跡（かかと・土踏まず・押し出された砂の縁）と解析勾配を生成。Oren-Nayar 粗面拡散反射、砂粒マイクログレイン、3 仮想光源からのリアルタイム・ソフトシャドウで、夕暮れの藍色の影と焚き火のオレンジの斜光を再現します。
- **流木ティピーと炭化枝の SDF 造形**: 正面の板薪の V 字の隙間、左右に伸びる流木、右枝を這い上がる小さな炎、炎の中を貫く黒く炭化した垂直枝を 3D SDF で構築。
- **黄昏の空と波打つ海**: 左上の群青〜右水平線の桃色・珊瑚色の夕焼けグラデーション、層状の夕暮れ雲、ドメインワープで自然な立体波と白波・濡れた波打ち際を表現。
- **深度遮蔽付き 3D 火の粉パーティクル**: インスタンシング描画による上昇・旋回する火の粉が、シーンの深度バッファ（alpha チャンネル）を使って薪の前後を自然にすり抜けます。
- **映画品質の HDR ポストプロセス**: Karis 加重ブライトパス、5段 13-tap Jimenez ダウンサンプル / 9-tap テントアップサンプル・ブルーム、暖色ハレーション、**AgX トーンマッピング**、レンズ周辺減光・微細フィルムグレイン。

### サウンド（無限プロシージャル Web Audio エンジン）
- **録音ループ不使用・完全に無限生成**: ブラウザ内でリアルタイム合成するため、継ぎ目や繰り返しがありません。
- **3 層の焚き火音響**:
  - 低い炎のうなり・燃焼音（視覚的な炎の揺らぎとリアルタイム連動）
  - 樹液や熾火のかすかな「チリチリ・ジュワ」音
  - ポアソン・クラスタスケジューラによる自然な「パチパチ」「バキッ」という薪のはぜる音（大きな破裂音に連動して 3D 火の粉も舞い上がります）
- **黄昏のさざ波**: 不規則な周期で寄せては返す波のうねり・砕け・引き波をステレオ定位で合成。

## 操作方法

| 操作 | 機能 |
| --- | --- |
| 画面下の「音をつける」または画面クリック | 焚き火・波の音をフェードイン再生 |
| 焚き火周辺をクリック / `Space` | 薪をくべる（炎・火の粉・パチパチ音が一時的に強まる） |
| マウス移動 | ごく穏やかな視差（パララックス） |
| `M` | サウンドのミュート / 解除 |
| `F` | 全画面表示の切り替え |
| `H` | UI の完全非表示（禅モード）切り替え |
| 設定ボタン | 焚き火 / パチパチ / 波の音バランス、空の時間帯（黄昏 / 藍時 / 夜更け）、画質（Ultra / High / Balanced） |

## ローカルでの起動

ビルド不要のネイティブ ES Modules 構成です。任意の静的 HTTP サーバーで配信してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開くと表示されます。
